# Central de documentação

Bem-vindo à documentação do AniT. Use este índice para encontrar rapidamente o material adequado ao seu objetivo.

- [Manual de utilização](USER_GUIDE.md): instalação, primeira estante, capas, episódios, avaliações e organização.

- [Privacidade e dados locais](PRIVACY.md): arquivos criados, consultas externas e exclusão de dados.
- [Suporte](../SUPPORT.md): onde tirar dúvidas ou relatar problemas.

## Fonte da verdade

Quando houver divergência:

1. o código e os testes definem o comportamento implementado;
2. o roadmap descreve intenção, não compromisso de entrega;
3. a documentação deve ser atualizada no mesmo pull request que altera um fluxo público.

Encontrou uma inconsistência? Abra uma issue de documentação ou envie um pull request pequeno e direto.
