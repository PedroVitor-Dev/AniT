# Arte decorativa da Home

Arquivo final: `assets/home/anime-horizon.png` (1536×1024, PNG). Recurso empacotado: `Assets/Home/anime-horizon.png`.

Gerado em 26/10/2026 com a ferramenta integrada ImageGen, para a Home Cinematográfica do AniT. A paisagem reúne referências ambientais a Naruto (vila ninja e montanha de líderes) e One Piece (navio de aventura). É uma ilustração gerada para o projeto, não uma capa oficial de anime. Não contém texto ou UI.

A arte aparece no banner quando não há episódio em destaque. O texto e as ações ficam em superfície separada com cores do tema. A imagem preserva a proporção e não depende de filtros ou inversão para funcionar no modo claro/escuro. No estado populado, as capas reais da biblioteca continuam sendo usadas. Prévias com dados fictícios reutilizam esta paisagem somente para demonstrar a composição sem mídias pessoais.
